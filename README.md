## 주요 명령어 및 작업 팁

### 1. 작업 재개

- `--resume` 또는 `continue`를 사용하여 이전 작업을 이어서 진행한다.

### 2. 컨텍스트 관리

- `/context`: 현재 AI가 기억하고 있는 작업 정보와 메모리 사용량을 확인한다.
- `/compact`: 컨텍스트를 압축하여 이후 작업을 위한 컨텍스트 공간을 확보한다.

※ **컨텍스트(Context)**: AI가 현재 작업을 위해 기억하고 있는 대화 내용, 파일 정보, 작업 내역 등을 의미한다.

### 3. 파일 참조

- `@`를 사용하여 특정 파일이나 폴더를 빠르게 참조한다.

### 4. 프로젝트 관리

- `/config`: 환경 설정을 관리한다.
- `/doctor`: 프로젝트 상태를 점검한다.
- `/export`: 작업 결과를 내보낸다.
- `/help`: 사용 가능한 모든 명령어를 확인한다.

### 5. 멀티모달 활용

- 캡처 도구를 사용하여 UI를 캡처한 후 드래그 앤 드롭으로 업로드한다.
- 업로드한 이미지를 기반으로 디자인 수정이나 시각적인 피드백을 요청할 수 있다.
